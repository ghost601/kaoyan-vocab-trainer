# 考研词汇训练器

面向考研英语的**主动回忆 + 间隔重复**背单词工具。纯前端、无后端、无账号，学习进度只存在你自己的浏览器里。

词表取自 **2027 考研英语红宝书**，学习顺序按**历年真题语料的真实词频**排列——考得多的先学，而不是照字母表硬啃。

```
6570 词   ·   五种题型   ·   8 级间隔重复   ·   单文件离线运行   ·   可装成手机 PWA
```

## 特性

- **按真题词频排序**：每个词带实际考频（`the` 86015 次 → 低频词 0 次），不浪费时间在无关词汇上
- **五种题型轮换**：闪卡 / 英→中 / 中→英 / 拼写 / 速筛，防止"看着眼熟"的假掌握
- **速筛四档分类**：认识、**认识但没记牢**、不认识、跳过——中间地带不被迫二选一
- **8 级间隔重复**：10 分钟 → 1 天 → 3 → 7 → 14 → 30 → 60 → 120 → 240 天，答错打回第 0 级
- **冲刺模式**：设定 30/45/60/90 天目标，每日配额自动按"剩余词数 ÷ 剩余天数"重算
- **误操作可回退**：常驻撤销按钮，移出的词可搜索找回，进度快照逐字段还原
- **数据三层防护**：实时写盘 + 持久化存储授权 + 绑定备份文件自动落盘
- **单文件 1.9 MB**：无外部依赖、无 CDN、断网可用；部署版可装到手机桌面完全离线
- **发音**：调用系统语音合成，自动挑选英文音色（本地语音优先）

## 快速开始

### 方式一：直接用

下载 `考研词汇训练器.html` 双击打开即可，无需安装、无需联网。

或者按 [部署指南.md](部署指南.md) 托管到 Cloudflare Pages / GitHub Pages，用手机随时访问。

### 方式二：从源码构建

需要 Node.js 18+。词表数据因版权原因不进仓库，构建前先获取：

```bash
git clone https://github.com/ghost601/kaoyan-vocab-trainer.git
cd kaoyan-vocab-trainer

node tools/fetch-data.mjs      # 从上游拉取词表与词频（约 2 MB）
node tools/build.mjs           # 生成 考研词汇训练器.html / Anki 包 / 学习计划

node tools/verify.mjs          # 可选：跑 184 项自动化校验
node tools/prepare-deploy.mjs  # 可选：生成带 PWA 的部署包
```

构建产物：`考研词汇训练器.html`（成品）、`build/kaoyan-anki.tsv`（Anki 导入包）、`学习计划.md`、`冲刺30天.md`。

## 使用方法

<details>
<summary><b>五种模式</b></summary>

| 模式 | 练什么 | 判分 |
| --- | --- | --- |
| 闪卡 | 主动回忆 —— 主力模式 | 手动按 1/2/3 |
| 英→中 | 识别速度，四选一 | 自动 |
| 中→英 | 产出能力，四选一 | 自动 |
| 拼写 | 真实拼写，逐字母对照 | 自动 |
| 速筛 | 快速分拣整库，四档分类 | 按 D / F / K / → |

选择题的干扰项来自同词性、词长相近的词，并排除与正确答案共享汉字的释义，避免出现"两个答案都对"。

</details>

<details>
<summary><b>速筛的四档（这套工具的独特之处）</b></summary>

速筛不是"认识 / 不认识"的二元判断。绝大多数词处在中间地带——见过、有印象、但不敢确定。把它们硬塞进两端，要么浪费新词配额，要么在考场上被打脸。

| 键 | 判断 | 后续处理 |
| --- | --- | --- |
| <kbd>K</kbd> | 秒懂，能直接拼写出来 | 永久移出，不再出现（可恢复） |
| <kbd>F</kbd> | **认识，但没记牢** | 立刻进今天的复习队列，**不占新词配额**；起始档位高一档，复习答对后间隔直接跳到 3 天 |
| <kbd>D</kbd> | 完全想不起来 | 同样进今天的队列、不占配额，但从 1 天起爬 |
| <kbd>→</kbd> | 走神、拿不准 | 什么都不记录，下次速筛还会遇到 |

`F` 和 `D` 都不占用每日新词配额——这点很关键：冲刺模式下新词额度是硬约束，让"其实见过"的词去抢额度是纯浪费。

标了 <kbd>F</kbd> 的词在后续复习时，卡片上会挂一个「速筛存疑」标记，提醒你评分时别手软。

</details>

<details>
<summary><b>快捷键</b></summary>

| 键 | 作用 |
| --- | --- |
| <kbd>空格</kbd> / <kbd>Enter</kbd> | 翻面 / 记住了 |
| <kbd>1</kbd> <kbd>2</kbd> <kbd>3</kbd> | 没想起来 / 有点印象 / 记住了 |
| <kbd>S</kbd> | 朗读当前单词（任何模式下都可用） |
| <kbd>K</kbd> | 永久移出（可找回） |
| <kbd>E</kbd> | 展开全部释义 |
| <kbd>→</kbd> | 跳过当前卡 |
| <kbd>Ctrl</kbd>+<kbd>Z</kbd> | 撤销上一次操作 |

速筛模式下：<kbd>D</kbd> 不认识、<kbd>F</kbd> 有点印象、<kbd>K</kbd> 已掌握、<kbd>→</kbd> 跳过，点卡片或按 <kbd>空格</kbd> 看释义。

</details>

<details>
<summary><b>误操作怎么办</b></summary>

只要本轮还有可回退的操作，屏幕右下角会常驻「↶ 撤销」按钮（多于一步时显示步数）。撤销会把词的数据**逐字段还原**成操作前的样子。

误移出的词还有另一层兜底：「数据」页的「已移出」区块列出所有被移出的词，支持按单词或中文释义搜索、单个恢复、一键全部恢复。恢复时立刻回到今天的队列，学过的话原 stage / 复习次数 / 错误数完整还原。

</details>

<details>
<summary><b>数据安全</b></summary>

进度**本来就自动保存**——每次评分都立刻写进浏览器存储，关页面、崩溃、重启都不丢。真正的风险只有两个：手动清缓存、换设备。三层层防护：

1. **持久化存储授权**：打开时静默申请 `navigator.storage.persist()`，防止浏览器在磁盘压力下自行清理
2. **绑定备份文件**（推荐）：选一个路径后，每次学习静默写回磁盘，清缓存也带不走它
3. **自动下载备份**：浏览器不支持文件绑定时，每清空一轮队列导出一份带日期的 JSON

> 进度存在 `localStorage`，按域名隔离。换网址、换浏览器、换设备都不会自动跟过去——用「数据」页的导出/导入迁移。

</details>

<details>
<summary><b>显示与发音设置</b></summary>

「数据」页可调**单词字号**四档（小 / 中 / 大 / 特大），释义字号联动，附带实时预览。长单词会自动缩一档，避免 `straightforward` 这类词撑破卡片。

发音入口三处：卡片右上角 🔊、评分栏最右 🔊、键盘 <kbd>S</kbd>。卡片右上角的**「自动朗读」开关**显示当前状态（开启时高亮实心圆点，关闭时灰色空心），点一下即切换。**手动点 🔊 永远有效，不受这个开关影响**——开关只决定翻面 / 判分后要不要自动读。

</details>

## 技术实现

<details>
<summary><b>间隔重复调度</b></summary>

8 级间隔，索引即 stage：`[10分钟, 1天, 3天, 7天, 14天, 30天, 60天, 120天, 240天]`

- 「记住了」升一级
- 「有点印象」原地踏步
- 「没想起来」打回第 0 级，当天稍后重现（同一轮最多补 2 次）

答错被打回是刻意设计：说明还没进入长期记忆，硬撑间隔等于两周后在考场上忘掉它。

每日新词配额在冲刺模式下按「剩余词数 ÷ 剩余天数」动态重算，当天固定——哪天落下了后面自动加回来，超前了自动减量。

</details>

<details>
<summary><b>词频分档与学习顺序</b></summary>

| 层 | 词数 | 判据 | 例子 |
| --- | --- | --- | --- |
| L3 高频考词 | 832 | 真题出现 ≥200 次 | the(86015), obtain(117) |
| L2 中频词 | 1325 | 50–200 次 | honest(52), obscure(44) |
| L1 低频词 | 4393 | <50 次或未收录 | revolt(4), zoom(0) |

学习顺序就是词频降序，卡片上的「真题 N 次」就是这个数字。

</details>

<details>
<summary><b>数据清洗（红宝书是 PDF 提取的，坑不少）</b></summary>

| 问题 | 表现 | 处理 |
| --- | --- | --- |
| 异体字 | `⻋辆`、`⽬标`、`⾼尚` | 康熙部首（U+2F00–U+2FDF）用 NFKC 还原；**CJK 部首补充区（U+2E80–U+2EFF）没有 NFKC 映射**，手工建了 23 字对应表 |
| 词性标记多样 | `det.` `vlink.` `modal.` `suff.` `ord.` | 全部纳入解析，否则词性前缀会混进释义正文 |
| 合法单字母 | `X 射线`、`X 光照片` | 早期为清理噪声写的"删孤立字母"规则会误删，已改为只清理「整条只剩单个字母」的义项 |
| 英美拼写差异 | `behavior`/`behaviour` | 用「其他拼写」字段加变体规则打通，避免同一个词算两遍 |

另外**首义词性按义项数量排序**，不用固定优先级——固定排序会把名词顶到最前，使 `accidental` 的首义变成 `n.次要方面` 而非 `adj.偶然的`。

</details>

## 开发

```bash
node tools/build.mjs     # 重新构建全部产物
node tools/verify.mjs    # 跑测试
node tools/audit-data.mjs # 检查词库质量
```

`verify.mjs` 覆盖脚本语法、数据质量、DOM 交互（jsdom 驱动真实点击流程）、冲刺配额、速筛四档、撤销、移出恢复、字号、备份与发音状态、部署包完整性。

交互测试依赖 jsdom，装一次即可：

```bash
mkdir -p .test-deps && cd .test-deps && npm init -y && npm install jsdom
```

## 已知边界

- 无音标数据，发音使用系统 TTS（Edge / Chrome 的英文语音），音色取决于本机
- 释义由红宝书词表提供，若发现可疑条目可加进 `tools/build.mjs` 的 `FIXES` 表逐条剔除
- 文件绑定功能依赖 File System Access API，Firefox / Safari 不支持，需改用自动下载备份
- 进度不跨设备同步（无后端），需要统一时用导出 / 导入
